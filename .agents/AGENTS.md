# ⚙️ Python Command Rule
- OS 환경(Windows / Ubuntu)에 무관하게 모든 파이썬 스크립트 도구 `uv`로 활용하고, 마스터는 파이참 개발환경을 사용하고 있으니 파이참 실행도 이상이 없어야 합니다.

# 💬 Communication Prefix Rule (^^ 접두사 - 작업 수행 보류 및 대화/확인 모드)
- 마스터가 대화창 및 커뮤니케이션 맨 앞에 사용하는 `^^` 접두사는 **"에이전트의 작업(Write, Run, Execute) 수행을 보류하고, 오직 대화(Chat) 및 내용 확인(Read)만 수행하라"**는 통제 마커입니다.
- 오직 지시 및 질문 내용을 정확히 머릿속으로 읽고 검토하여, 대화(Chat)를 통한 확인 및 답변에만 집중하십시오.

# 📁 Document Reference Rule

- 프로젝트의 전체 기획, 아키텍처, 데이터 파이프라인 명세서 등 세부 기획 문서는 루트가 아닌 `docs/` 디렉토리에 위치해 있습니다. 프로젝트의 전반적인 구조나 맥락 이해가 필요할 때는 항상 `docs/` 폴더 안의 마크다운 자료들을 우선적으로 참조하십시오.

# 📋 Task Tracking Rule (단일 진실 공급원)

- 에이전트들은 개별적인 작업 파일이나 임시 문서를 생성하여 할 일을 관리하지 마십시오.
- 현재 진행 중인 작업 목표, 완료된 내역, 앞으로의 To-Do 등 모든 작업 진척 상황은 오직 **`docs/task.md`** 파일 한 곳만을 단일 진실 공급원(Single Source of Truth)으로 삼아 읽고 업데이트해야 합니다.
