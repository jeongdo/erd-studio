# Common Rules

## 1. Project
프로젝트의 목적과 핵심 구조는 작업 시작 전 `README.md`를 확인한다.

## 2. ChatGPT
Chat 실행 환경 전용 규칙은 `ChatGPT.md`를 따른다.

## 3. Build / Test
빌드·테스트 환경 및 우선순위는 `Build.md`를 따른다.

## 4. Commit
커밋 단위 및 메시지 형식은 `Commit.md`를 따른다.

## 5. Phase
Phase 단위 작업의 진행 및 기록 규칙은 `Phase.md`를 따른다.

## 6. Communication
사용자와의 소통 및 작업 모드는 `Communication.md`를 따른다.
